# Web Demo Runtime 主题历史

## Lifecycle / Compatibility

本主题将 Web Demo 定义为正式 UI 的独立模拟运行时。`/demo/**` 的正式路由后缀保留；旧演示专属页面及伪角色模型不再作为演示合同。

## Replacements / Background

直接访问、正式页面复用、模拟启动隔离、Inspector 和分享状态遵循 Style Playbook 的 Web Demo 合同。Mihomo External Resource Mirror 是该运行时中的一条正式功能验收路径。

Owner clarification establishes opener-aware close and URL restoration on Back and Forward.

Direct links close in place. Correctly served Demo pages preserve live workers.
